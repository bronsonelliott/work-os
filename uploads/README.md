# Uploads

Put documents here, or paste text into the chat and Claude saves it here: weekly summaries, ticket exports, performance reviews, peer feedback, your job's skill rubric. Text, PDFs and screenshots all work.

Then say "file this" or "what does this review say about me?"

Claude names each file `YYYY-MM-DD_what-it-is`, leaves the original unchanged, and cites it from the entries it creates.
