# Uploads Directory

This folder stores:

1. **past_reviews/** - Upload performance reviews, 360 feedback, and other external documents here
2. **document_synthesis.md** - Extraction log (what Claude extracted from each upload)
3. **pattern_summary.md** - Patterns across all uploaded documents (recurring strengths, gaps, trajectory)

## How to Use

Upload a document and say: "Extract patterns from this review"

Claude will:
1. Read the document
2. Extract themes, strengths, feedback, signals
3. Update document_synthesis.md (extraction log)
4. Update pattern_summary.md (patterns across all uploads)
5. Update memory.md (key insights)
6. Show you what was found

---

## Examples to Upload

- Annual performance reviews
- 360-degree feedback results
- Manager feedback letters
- Performance evaluation documents
- Career development assessments

Claude will track patterns across all documents and show you:
- What strengths keep coming up
- What gaps are persistent
- How your career trajectory looks
- Blind spots (where you might be missing something about yourself)
